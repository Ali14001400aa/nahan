📖 Overview & Architecture

Comprehensive overview of Project Nahan Gateway v3.1.0 capabilities

⚡ Dual Protocols

Seamless VLESS and Trojan protocol demuxing over Cloudflare WebSockets with native cloudflare:sockets TCP connection pipelining.

🤖 AI Smart Egress Tagging (`#AI`)

To prevent ChatGPT, Claude, and Gemini from blocking Cloudflare datacenter egress IPs, append #AI to clean residential or VPS relay endpoints:

194.56.78.90:443#Frankfurt#AI, 185.120.30.40:8443#Amsterdam#AI

When clients access AI domains (openai.com, gemini.google.com, etc.), Nahan Gateway automatically prioritizes #AI relays.

💻 Wrangler CLI Deployment

Commands for terminal-based local development and production deployment

1. Initialize and Create D1 Database

npx wrangler login
npx wrangler d1 create nahan-db

2. Update wrangler.toml with your database ID

name = "nahan-gateway"
main = "worker.js"
compatibility_date = "2024-03-01"
compatibility_flags = ["nodejs_compat"]

[[d1_databases]]
binding = "IOT_DB"
database_name = "nahan-db"
database_id = "YOUR_DATABASE_UUID_FROM_STEP_1"

3. Deploy to Cloudflare

npm run deploy
# or: npx wrangler deploy
